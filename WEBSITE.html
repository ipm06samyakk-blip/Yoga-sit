// Machine Learning

Two Algorithms, One System

The hybrid approach blends content-based filtering with rating prediction for superior personalisation.

📐

Cosine Similarity (Unsupervised)

Measures the angle between two movie rating vectors in high-dimensional space. If many users rated two movies similarly, the angle between them is small — meaning high similarity.

cos(θ) = (A · B) / (‖A‖ · ‖B‖)
# Result: 9,719 × 9,719 similarity matrix
# Each cell: similarity score [0, 1]
🌲

Random Forest (Supervised)

An ensemble of 50 decision trees trained on (userId, movieId) → rating pairs. Each tree votes; the average prediction gives a continuous rating estimate between 1.0 and 5.0.

ŷ = (1/N) · Σ tᵢ(userId, movieId)

def recommend_for_user(user_id, n_recommendations=5): # Find movies the user already rated user_ratings = data[data['userId'] == user_id] # Get user's top 3 favourite movies favorite_movies = user_ratings.sort_values( by='rating', ascending=False )['title'].head(3) recommendations = [] for movie in favorite_movies: similar = similarity_df[movie].sort_values( ascending=False ).iloc[1:6].index.tolist() recommendations.extend(similar) return list(set(recommendations))[:n_recommendations] # Test it! recommend_for_user(1) # → ['Forrest Gump (1994)', 'Rushmore (1998)', ...]
